# استعلام نتائج الطالبات

صفحة ويب عربية لطالبات الصف الثاني: يُكتب رقم الهوية فتظهر بطاقة النتيجة.

تعرض البطاقة اسم الطالبة والفصل، ومتوسط الاختبارين الأول والثاني، والمشاركة، والمشاريع والمهام، والواجبات والاختبار النهائي (إذا حددت المعلمة درجتهم العظمى)، ونمط التعلم، والإيميل الوزاري، مع عبارة تشجيعية حسب النتيجة. ملاحظات المعلمة تبقى في لوحة التحكم ولا تظهر للطالبة. المعلمة: فائزة محمد جبوع، والمديرة: د. حنان المطيري.

## التشغيل

سيرفر Node (Express) يقدّم الصفحة من مجلد `public` ويستعلم عن الطالبة من قاعدة PostgreSQL.

| المتغير | الوصف |
|---|---|
| `DATABASE_URL` | رابط اتصال قاعدة PostgreSQL (في Render: Internal Database URL) |
| `PORT` | اختياري، يضبطه Render تلقائياً |

يُنشئ السيرفر جدول `students` تلقائياً عند التشغيل إذا لم يكن موجوداً. على Render يُبنى المشروع من `Dockerfile`.

محلياً:

```bash
npm install
DATABASE_URL=postgres://... npm start
```

## البيانات

بيانات الطالبات في جدول `students` داخل القاعدة فقط، وليست في المستودع. تُعبّأ القاعدة بملف `seed.sql` (غير مرفوع):

```bash
psql "<External Database URL>" -f seed.sql
```

الواجهة تطلب `POST /api/lookup` برقم الهوية، والسيرفر يحدّ المحاولات لكل جهاز بـ 30 محاولة كل 10 دقائق.
