# استعلام نتائج الطالبات

صفحة ويب عربية لطالبات الصف الثاني: يُكتب رقم الهوية فتظهر بطاقة النتيجة.

تعرض البطاقة اسم الطالبة والفصل، ومتوسط الاختبارين الأول والثاني، والمشاركة، والمشاريع والمهام، والتأخير، ونمط التعلم، والإيميل الوزاري، مع عبارة تشجيعية حسب النتيجة. المعلمة: فائزة محمد جبوع، والمديرة: د. حنان المطيري.

## التشغيل

الصفحة ملف واحد `index.html` بدون مكتبات، يكفي فتحه في المتصفح.

## البيانات

كل سجل طالبة محفوظ داخل الثابت `VAULT` مشفّراً (AES-GCM) بمفتاح مشتق من رقم هويتها (PBKDF2). ملفات الإكسل مستبعدة من المستودع عبر `.gitignore`.
